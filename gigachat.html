1. Начало работы

Теория

Python — интерпретируемый язык программирования. Код выполняется строка за строкой. Для запуска кода используется интерпретатор.

# Это комментарий
print("Привет, GigaCamp!")

2. Типы данных

Теория

Основные типы: int (целые), float (дробные), str (строки), bool (булевы: True/False). Python — язык с динамической типизацией.

age = 25
price = 19.99
name = "Алексей"
is_student = True

3. Условия и циклы

Теория

Для ветвления используется if-elif-else. Для повторения действий — циклы for и while. Отступы (4 пробела) определяют блоки кода.

for i in range(5):
    if i % 2 == 0:
        print(f"{i} - четное")
    else:
        print(f"{i} - нечетное")

Упражнение 3.1

4. Функции

Теория

Функции позволяют изолировать логику. Определяются через ключевое слово def. Могут принимать аргументы и возвращать значения.

def greet(person):
    return f"Привет, {person}!"

print(greet("Мир"))

Упражнение 4.1

5. Структуры данных

Теория

Список (list) — изменяемая последовательность. Кортеж (tuple) — неизменяемая. Словарь (dict) — пары ключ-значение.

fruits = ["яблоко", "банан"]
print(fruits[0]) # яблоко

user = {"name": "Олег", "level": 1}
print(user["name"]) # Олег

Упражнение 5.1

6. Объектно-ориентированное программирование (ООП)

Теория

ООП строится на классах и объектах. Класс — чертеж, объект — конкретная реализация. Основные принципы: инкапсуляция, наследование, полиморфизм.

class Dog:
    def __init__(self, name):
        self.name = name
    
    def bark(self):
        print(f"{self.name} говорит: Гав!")

rex = Dog("Рекс")
rex.bark()

Упражнение 6.1
